Hành trình học lập trình web từ con số 0

8/05/2026

Tác giả: Bình Thuận

Nội dung bài viết

Lập trình web là một lĩnh vực rất rộng và hấp dẫn. Khi mới bắt đầu tôi cảm thấy khá khó khăn với HTML , CSS và JavaScript .

HTML giúp xây dựng cấu trúc trang web còn CSS giúp tạo giao diện đẹp mắt. JavaScript giúp web trở nên tương tác hơn .

Một điều quan trọng mà tôi học được là phải luyện tập thường xuyên. Việc viết code mỗi ngày giúp cải thiện kỹ năng nhanh chóng.

Khi làm dự án thực tế, tôi nhận ra rằng Thực hành quan trọng hơn lý thuyết.

ví dụ để thay đổi background color khi chọn tôi dùng 

            
                ::selection{
                    background-color: #cd2c2c;
                    color:blue;
                }

Để lưu file nhanh trong trình soạn thảo, tôi thường dùng: Ctrl + S

Khi chạy code thành công, kết quả in ra màn hình Hello world
